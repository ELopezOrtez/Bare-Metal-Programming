<b>Blinking A Physical LED</b>
Purpose: To answer a question that I proposed to myself in school. The question being "how did my professor create the contents within the header file, and create the setup within main.c?"<br>
         I answered this question by buying another microcontroller separate from the one we used in class. The microcontroller that I bought was the STM32 Nucleo-F446RE. I utilized this <br>
         controller to accomplish a basic project that I called "Testing_Manual_Way". <br>

Objective: Testing_Manual_Way needs to blink a physical LED light on and off. The method to completing this project and answering the question that I made to myself was to go the bare-metal route.
