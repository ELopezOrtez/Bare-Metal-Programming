<b>1. Blinking A Physical LED</b>

Purpose: <p>To answer a question that I proposed to myself in school. "How did my professor create the contents within the header file, and create the setup within main.c from scratch?"
         For context, we used the EK-TM4C1294XL; however, I bought the STM32 Nucleo-F446RE to answer my question. I utilized this controller to accomplish a project that I called "Testing_Manual_Way".</p> 

Objective: <p>The project needs to blink a physical LED light on and off, repeatedly. The approach I used was the bare-metal programming. I did not want to use any pre-existing libraries or hardware abstraction layers.
              Similar to my professor, I wanted to do this from the ground up.</p>

Process: <p>To achieve this goal and answer my question, I utilized the datasheets on Nucleo-F446RE from the STM32 website. Furthermore, I used AI for general concepts such as "What is an RCC? How does a RCC structure look like?"
             However, I crossed reference the output from the AI to the datasheets for accuracy. Lastly, I wrote the code that utilizes the GPIOx, RCC, SysTick, memory addresses, and anything in between</p>
